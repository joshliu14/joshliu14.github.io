Live Sep 2026 – Present · Medford, MA

Tufts Datacenter Systems Lab

Graduate Researcher

Why is CPU inference leaving cores on the bench?

Most conversations about ML inference are about GPUs, but plenty of real-world inference runs on CPUs. I'm profiling CPU inference of machine-learning models with Linux perf to see where the time actually goes: which bottlenecks are memory-bound, which are compute-bound, and which cores sit underutilized.

Next up: developing optimizations that maximize CPU utilization and cut inference latency.

Jun 2024 – May 2025 · Brandeis

Core Machine Learning Lab

Undergraduate Researcher · with Prof. Hongfu Liu

Feature selection, minus the retraining.

Wrapper methods choose features by retraining a model on candidate subsets over and over: accurate, but expensive. Influence functions estimate how a model would change without retraining it, and Hessian-free variants skip the costly inverse-Hessian step. I researched using them to make wrapper methods more computationally efficient.

  • Influence functions
  • Feature selection
  • Optimization
